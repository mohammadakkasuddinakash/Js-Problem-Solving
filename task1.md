# Task 1: Supermarket Return Money

## Problem Statement

You went to the supermarket to buy some oranges and apples. Calculate how much money the shopkeeper will return.

## Input

* The first line of the input contains the amount of taka you have.
* The second line contains the cost of 1 kg of oranges and 1 kg of apples.

## Output

Print the amount of money the shopkeeper will return.

## Sample Input

```text
1000
700
```

## Sample Output

```text
300
```
## Explanation

You have **1000 taka**.

The total cost of 1 kg of oranges and 1 kg of apples is **700 taka**.

Therefore, the shopkeeper will return:

```text
1000 - 700 = 300
```

So, the output is:

```text
300
```
